# Onshape icons

SVG icons from Onshape's UI, for `fs ui` (see `fs_cli/ui.py`) to draw dialogs the way Onshape does. Open
`index.html` to browse them by number.

They're numbered in the order they were captured, and the numbers are what code refers to, so files are never
renumbered. Exact copies were removed, leaving gaps. Some icons are the same shape in a different color (e.g. a
feature's normal, hovered, and disabled states, or an error and a warning), and some are white, for dark
backgrounds; those are kept.

# Onshape std library

The [Onshape FeatureScript standard library](https://cad.onshape.com/documents/12312312345abcabcabcdeff),
version **2960.0**, for reference (and for the language server's stdlib indexes). It's MIT licensed;
see `LICENSE.txt`.

Version numbers are replaced with `✨` to keep diffs between std versions small.

Source: https://github.com/javawizard/onshape-std-library-mirror/tree/a2a7b13ea823f144b20d27198043aea35a64d928 (without-versions branch, 2026-05-15)

Don't edit these files. Update them with:

```
uv run python -m fs_lsp.tools.update_stdlib
```
